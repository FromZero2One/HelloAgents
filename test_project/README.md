# test_project

HelloAgents 项目

## 快速开始

```bash
# 安装依赖
pip install -r requirements.txt

# 配置环境变量
cp .env.example .env
# 编辑 .env 填入你的 API Key

# 运行
python main.py
```

## 目录结构

```
.
├── agents/      # 自定义 Agent
├── tools/       # 自定义工具
├── skills/      # 技能文件
├── config/      # 配置文件
├── main.py      # 入口文件
└── .env         # 环境变量（不提交）
```
